# 606-Chunk Reference Baseline

This directory preserves the historical 400/60 retrieval baseline used for reproducibility and comparison.

- It contains 606 chunks generated with the BGE-M3 tokenizer.
- Its PDF002 document covers all 43 pages, before the Final corpus restored the intended page 17–19 scope.
- Its evaluation dataset has 120 records; 28 records have different 400/60 gold mappings from the boundary-corrected Final dataset.
- The Test40 JSON is the executed aggregate result for this historical baseline.

This snapshot is not the production or current source of truth. The Final 563-chunk corpus, Final dataset, and canonical results remain in their existing repository paths.
